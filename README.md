# Лаймо Банк

Демонстрационный мобильный сайт банка: Главная, Тариф, Расходы и Поддержка. Основной текущий фокус — точное воспроизведение меню iOS с тонированным жидким стеклом, включая мелкие детали и плавность.

[Открыть сайт](https://f4hrut.github.io/webtest/?v=123)

## Продолжение работы в любом чате

Перед изменениями модель должна прочитать:

1. [AGENTS.md](AGENTS.md) — обязательные правила работы и обновления контекста.
2. [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md) — актуальное устройство кода, тонкости Safari, состояние, проверки и передача следующему чату.
3. [CLAUDE.md](CLAUDE.md) — исходная подробная история работы с Claude Code и измерений; старые решения сверять с актуальным контекстом и кодом.

Контекст хранится здесь, на GitHub, и обновляется после каждой завершённой правки вместе с кодом. Новый чат не должен зависеть от локальных отчётов или памяти старого разговора.

Можно дать модели такую задачу:

> Продолжай работу над Лаймо в F4hRuT/webtest на GitHub. Сначала прочитай README.md, AGENTS.md, docs/PROJECT_CONTEXT.md и CLAUDE.md, проверь текущий код и раздел передачи работы. Соблюдай правила и обнови контекст после правки. Задача: …

## Исходники и запуск

- `index.html` — страница банка, её CSS, SVG и JS.
- `menu.js` — меню, анимации, линза и стекло.
- `test/` — страницы сравнения и диагностики; это не всегда копии текущей страницы.
- `tools/` — UIKit-эталоны и инструменты замеров.
- [tools/validation/README.md](tools/validation/README.md) — проверенные команды и скрипты диагностики Safari/симулятора, PNG и видео.

Сборка и npm-зависимости не нужны. Для локальной проверки из корня проекта:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/` в доступном тестовом браузере. Правила проверки iOS и ограничений устройств — в AGENTS и контексте. Остановить запущенный сервер после работы.

GitHub Pages настроен на ветку `main`, корень. Текущая версия приложения на момент подготовки документации — v123; перед работой сверять с кодом.
